# Note App Project

A compact, single-page Note App that allows users to:

Add quick notes

Display notes in a simple card layout

Remove notes easily with a double click

Manage small pieces of information quickly


## 📝 What Does It Do?

The app allows users to create and manage simple notes:

Add Note: Users can create a new empty note by clicking the "+" button.

Write Notes: Users can type any text inside the note card.

Remove Notes: Double-clicking a note deletes it instantly.

Quick Organization: Notes are displayed in a clean grid layout for easy viewing.

The interface is minimal and user-friendly, designed for quick note-taking and fast interaction.


## ⚙️ How Does It Work?

Single-page structure: Built using HTML, CSS, and JavaScript.

Event handling: Clicking the "+" button creates a new note card.

Editable content: Notes can be written directly inside the note area.

Double-click interaction: Double-clicking a note removes it from the page.

Dynamic DOM manipulation: Notes are created and removed instantly without refreshing the page.

Lightweight implementation: Built with pure JavaScript — no external libraries used.
